# 🎓 Student Registration Form

Sistema de cadastro de alunos desenvolvido em **HTML5 e CSS3**, com o objetivo de coletar e organizar informações pessoais, endereço e dados acadêmicos dos estudantes através de uma interface web simples, clara e responsiva.

---

## 📋 Funcionalidades

* Cadastro de dados pessoais do aluno
* Registro de informações de contato
* Cadastro completo de endereço
* Registro de informações acadêmicas
* Seleção de disciplinas favoritas
* Campo para observações adicionais
* Botões de envio e limpeza do formulário
* Interface organizada com uso de `fieldset` e `legend`

---

## 🛠️ Tecnologias Utilizadas

* HTML5
* CSS3
* Google Fonts (Poppins)

O sistema possui três seções principais:

* **Dados Pessoais**
* **Endereço**
